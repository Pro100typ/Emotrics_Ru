# Emotrics_Ru
Русифицированная и доработанная версия Emotrics - инструмента для оценки асимметрии лица. Добавлена поддержка кириллицы в путях, портативная сборка, расширенный экспорт данных (Excel с диаграммами, размеченные фото, TXT) и улучшенная обработка ошибок.

A Russian-localized and enhanced version of Emotrics, a tool for the assessment of facial asymmetry. Improvements include support for cyrillic characters in file paths, a portable build, expanded data export options (Excel with charts, annotated photos, TXT), and improved error handling.
