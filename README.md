# Emotrics RU

Русифицированная и улучшенная версия программы **Emotrics** - инструмента для автоматизированной оценки асимметрии лица у пациентов с параличом лицевого нерва. Программа основана на открытом исходном коде [Emotrics](https://github.com/dguari1/Emotrics) (разработчик: Diego L. Guarin, PhD, Massachusetts Eye and Ear Infirmary, Harvard Medical School).

## В рамках доработки выполнены следующие улучшения:

### 1. Полная русификация интерфейса
- Переведены все элементы меню, подписи, сообщения об ошибках и справка.
- Названия метрик приведены в соответствие с требованиями врачей Новосибирского Федерального Центра Нейрохирургии.

### 2. Поддержка кириллицы в путях к файлам
- Реализованы Unicode-совместимые функции чтения и записи изображений (`imread_unicode`, `imwrite_unicode`).

### 3. Расширенный экспорт результатов
- Добавлена возможность сохранения:
  * Исходных и размеченных фотографий пациента.
  * Координат разметки лица в TXT-файл.
  * Скана согласия.
  * Excel-отчёта с комментариями врача, метриками и диаграммами изменений (в случае загрузки двух фотографий)
- Все файлы сохраняются в одну папку, выбранную пользователем.

### 4. Дополнительные поля для клинических данных
- В окно сохранения добавлены поля: ФИО пациента, дата рождения, дата съёмки (автоматически извлекается из метаданных фотографии), диагноз, процедура, выражение лица, комментарии, скан согласия.

### 5. Удаление устаревших элементов
- Убрана функция импорта позиции радужки из файла.
- Удалены поля ID пациента и ID фото (автоматически используются имена файлов).

## Установка и запуск

### Вариант 1: Готовый EXE
Скачайте `Emotrics.exe` из раздела [Releases](https://github.com/Pro100typ/Emotrics_Ru/releases) и запустите.

### Вариант 2: Запуск из исходного кода
1. Установите Python 3.11.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
3. После успешной установки программу можно запустить:
    ```bash
    python Emotrics.py
